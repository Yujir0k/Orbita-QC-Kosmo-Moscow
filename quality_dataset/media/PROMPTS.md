# Как получены демонстрационные изображения

Режим: встроенный `image_gen`, генерация базовых снимков и последовательное редактирование по предыдущему кадру. Изображения искусственные и обозначены в `expanded_dataset/media_index.json`.

| Файл | Краткий промпт и неизменяемые детали |
| --- | --- |
| `item-013-cv-scratch.png` | Фотореалистичный кадр промышленной камеры: алюминиевый кронштейн с двумя отверстиями и центральным каналом в тёмном приспособлении, жёлтая круглая метка, диагональная риска у правого отверстия. Мягкие шум/сжатие, дефект виден. |
| `item-013-master-clear.png` | Редактирование того же кронштейна: убрать только риску после контролируемой доработки; сохранить отверстия, канал, стапель, жёлтую метку и ракурс. Чёткое фото после работы. |
| `item-014-cv-burr.png` | Другой алюминиевый кронштейн в чёрном стапеле, синяя круглая метка слева снизу, один заусенец на внешней правой кромке. Умеренно шумный промышленный кадр. |
| `item-014-master-burr-remains.png` | Тот же кронштейн после первой обработки: сделать кадр чётче, **сохранить заусенец** в той же точке; остальные детали неизменны. |
| `item-014-master-clear.png` | Редактирование второго снимка: убрать только заусенец на правой кромке после второго прохода; сохранить геометрию, фон и синюю метку. |
| `item-015-master-dent.png` | Первое пригодное фото после потери кадра камеры: кронштейн на тёмном коврике с оранжевой круглой меткой, повреждение наружной левой кромки. Чёткий снимок мастера. |
| `item-016-cv-glare.png` | Промышленный кадр чистого кронштейна с зелёной круглой меткой: яркий блик на правой поверхности похож на царапину; умеренный шум, реального дефекта нет. |
| `item-016-master-clear.png` | Тот же чистый кронштейн при рассеянном освещении: убрать только блик, показать целую поверхность; сохранить стапель, метку, отверстия и канал. |

Общие ограничения всех промптов: один предмет, узнаваемая геометрия внутри каждого сценария; без людей, текста, стрелок, рамок, логотипов и водяных знаков. Снимки не претендуют на измерительную точность.
